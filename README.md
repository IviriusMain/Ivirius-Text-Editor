## ✨ Features Comparison

Below is a feature comparison between **WordPad**, **Ivirius Text Editor**, and **Ivirius Text Editor Plus**. The differences range from enhanced text editing options to entirely new capabilities. Note that WordPad and Ivirius Text Editor are based on different technologies, so exact feature parity isn’t guaranteed.

| Feature                                  | WordPad               | Ivirius Text Editor       | Ivirius Text Editor Plus                        |
| ---------------------------------------- | --------------------- | ------------------------- | ----------------------------------------------- |
| **RTF Editing Support**                  | 🟡 Basic formatting   | 🟡 Extended formatting   | ✅ Full RTF editing                             |
| **Object Insertion**                     | 🟡 Legacy RTF objects | 🟡 Images, date/time     | ✅ Images, date/time, tables, screenshots, etc. |
| **Import / Export Formats**              | 🟡 Limited            | ✅                       | ✅                                              |
| **Themes**                               | ❌                    | 🟡 Default WinUI styling | ✅ Advanced styling *(coming soon)*             |
| **Tabs**                                 | ❌                    | ✅                       | ✅                                              |
| **Setup / Installer**                    | ❌                    | ✅                       | ✅                                              |
| **Word Count**                           | ❌                    | ✅                       | ✅                                              |
| **Home Page**                            | ❌                    | ❌                       | ✅                                              |

## 🤖 Zippy

Zippy is the built-in AI assistant exclusive to **Ivirius Text Editor Plus**. Powered by the [pollinations.ai](https://pollinations.ai/) API, Zippy brings smart AI features right to your fingertips — no complex setup needed, just seamless remote integration capable of running on all configurations.

Interact with Zippy by clicking on him in his tiny container to open a menu of fun and helpful actions. Just a heads-up: be kind to Zippy! If he gets sad, he’ll lose his vibrant colors and cheerful personality. Don't forget to give him a treat every once in a while 😉

> [!WARNING]
> Zippy requires an active internet connection to function properly. Since pollinations.ai relies on donations, you may occasionally see ads in Zippy’s responses.

## 🧑‍💻 Contributing

This project is currently **not open for public contributions**. However, if you believe you have the skills and passion to contribute, consider applying to join the Ivirius Team. Please note that all team work is **voluntary** — no paychecks or salaries are offered.

Curious why this project isn’t publicly available under a restrictive license? You can learn more in the [FAQ section](https://ivirius.com/docs/) on our docs home page.

We plan to open up **localization contributions** soon, allowing the community to help translate the app without joining the core team. Stay tuned for updates!
